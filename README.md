# Cédric Baer — Technical Writer Portfolio

## V7 — Terre et Nuage

Palette based on Media.io's **Terre et Nuage / Clay and Cloud**:

- `#1c2230` — primary dark blue-grey: main typography and dark structure
- `#3d4a5c` — secondary blue-grey: supporting text and secondary structure
- `#b7c3d0` — border blue-grey: borders, separators and quiet UI details
- `#eef2f6` — cloud: page backgrounds and large light sections
- `#c46a5a` — terracotta: CTA buttons, timeline markers, links and small accents

### Design rules

- Dark blue-greys carry the typography and hierarchy.
- Cloud tones dominate large surfaces and cards.
- Terracotta is deliberately limited to interactive or directional elements.
- Borders use `#b7c3d0`.
- Shadows are deliberately subtle.
- Cards remain mostly white/cloud so the portfolio stays light and readable.

### Typography

- **IBM Plex Sans** — headings, navigation, labels, buttons and UI
- **Source Serif 4** — body copy and longer reading
